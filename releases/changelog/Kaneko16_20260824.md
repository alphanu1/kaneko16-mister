# Kaneko16_20260824.rbf

md5 `e662d4543ee88aaf10d0e004316e6347`, 3,936,852 bytes.

The first release with all four Tier 1 games playable. Reconstructed from the
repository history: this build predates the per-release changelogs, and was
recovered off the SD card rather than from `build/`, so it has no recorded fit
numbers.

## Games

**Magical Crystals now runs.** Two independent faults kept it black. Its MRA
carried no 68000 program ROM at all, because its two program ROMs are different
sizes and the region emitter assumed the interleave lanes were symmetric; and
six DIP bits at `c00000` were driven low where the board pulls them high, which
failed a boot check and left the 68000 masked at level 7, refusing interrupts
it could see being raised.

**Blaze On plays.** Its second sprite register window at `980000` is RAM, not a
register bank, and its input words are ordered differently from the other
board — `P1/P2/UNK/SYSTEM` rather than `P1/P2/SYSTEM/UNK`. Its SYSTEM port also
declares only its high byte, so the idle word is `0xFF00` and not `0xFFFF`; the
game tested the low byte and jumped to its park loop.

**Wing Force plays**, with in-game music.

## Options

- `Flip screen` removed. It read the DIP and did nothing visible, because the
  game flips its own rendering and this core does not implement that. Screen
  orientation is `Rotation`, which is a different mechanism.
- `Rotation`: Off / Auto (per game) / CW / CCW.

## Known issues at the time of release

- Explosive Breaker: enemy sprites and the opening boss reported missing by a
  third party. Not reproducible on the machine this was built on. Later
  bisected to a change that was never in this build.
- Wing Force: no OKI sound effects. Fixed after this release.
- Tier 2 and Tier 3 not attempted.
